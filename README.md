A deterministic, stdlib-only Python program that writes one line to `/output/entry.txt`: the phone battery's last text message to the charger it waited for all day. Left at 2% while everything else got charged, the battery stops begging and starts negotiating — with the one thing the charger can't afford to lose.

> Left me at 2% all day while you charged your watch, your vape, and your AirPods twice. Plug me in now, or your 6 a.m. alarm dies with me.

## Run it

```sh
python3 main.py
```

The program writes the single 137-character line to `/output/entry.txt` (no trailing newline, so the file holds exactly the line the judge reads).
